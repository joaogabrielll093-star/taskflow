  1. Abra este endereço no Safari.
  2. Toque em Compartilhar.

  4. Abra o TaskFlow pelo novo ícone.

Como usar o mapa

  • PlanetaCada tarefa pendente é um planeta. Toque nele para abrir, concluir ou adiar.
  • ÓrbitasQuanto mais perto do sol, mais perto o prazo: Atrasadas, Hoje, Amanhã, Esta semana, Depois e Sem prazo.
  • MoverSegure um planeta e arraste para outra órbita para mudar o prazo.
  • CriarSegure no espaço vazio para criar uma tarefa já naquela órbita. Ou use o foguete.
  • NavegarArraste para andar pelo espaço, pince ou use a roda do mouse para o zoom.
  • SolA coroa mostra quantas tarefas de hoje você já concluiu. Toque nele para ver o resumo.
  • SinaisO tamanho mostra a prioridade. A cauda de cometa vermelha marca atraso.
  • PlanetasCada tarefa vira um corpo do sistema solar. A repetição vem primeiro, depois a prioridade alta, depois o prazo.
  • SaturnoTarefa que se repete.
  • JúpiterPrioridade alta, de qualquer categoria. O maior de todos.
  • UranoSem prazo, na órbita externa.
  • NetunoPara depois, além desta semana.
  • TerraPessoal, prioridade média.
  • MarteTrabalho, prioridade média.
  • MercúrioPessoal, prioridade baixa.
  • VênusTrabalho, prioridade baixa.
  • LuaSubtarefa. Gira ao redor do planeta.
  • SolSeu progresso do dia.
  • GaláxiaTarefas concluídas viram estrelas distantes. Afaste o zoom para ver sua constelação.
  • ListaO botão à esquerda do foguete alterna entre o mapa e a lista clássica.
